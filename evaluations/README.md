# Evaluation assets

- `cases.json` is the minimum contract-level risk inventory.
- `keyless-benchmark.json` defines the paired scripted fault matrix executed through the real Harness agent loop.
- `latest-keyless-report.json` is the reproducible mechanism-level result generated by `npm run benchmark:keyless`.
- `live-benchmark.json` defines the pre-registered v4 three-arm protocol, 20 real-model tasks, repair classes, claim-coverage telemetry, thresholds, MDE assumptions, and independent filesystem/JSON oracles. It evaluates the default task-agent authoring path, not v0.5's experimental auxiliary-author option.
- `live-benchmark.preregistered.json` locks the manifest, runner, and analysis hashes before provider-backed execution.
- `latest-live-report.json` is created only after an authorized provider-backed run.

The keyless suite proves enforcement mechanics. Only the live suite can support a claim about a named model's behavioral improvement. Its three arms separate baseline behavior, model-authored contracts, and independently authored reference contracts. See [the benchmark protocol](../docs/BENCHMARK.md) for outcome tables, false-rejection costs, clustered inference, power limits, repair-transition caveats, and verdict gates.

A one-off successful transcript is not evidence of stability.
