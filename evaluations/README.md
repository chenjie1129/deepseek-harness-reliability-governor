# Evaluation assets

- `cases.json` is the minimum contract-level risk inventory.
- `keyless-benchmark.json` defines the paired scripted fault matrix executed through the real Harness agent loop.
- `latest-keyless-report.json` is the reproducible mechanism-level result generated by `npm run benchmark:keyless`.
- `live-benchmark.json` defines 20 paired real-model tasks and independent filesystem/JSON oracles.
- `latest-live-report.json` is created only after an authorized provider-backed run.

The keyless suite proves enforcement mechanics. Only the live suite can support a claim about a named model's behavioral improvement. See [the benchmark protocol](../docs/BENCHMARK.md) for metrics, power limits, cost controls, and verdict gates.

A one-off successful transcript is not evidence of stability.
